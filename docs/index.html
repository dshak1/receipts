Claims are not outcomes

A green toast or a final click is not proof. Deterministic checks decide what happened.

Failures have a type

False positive, silent success, agent failure, timeout, and environment error tell different stories.

Evidence travels with the run

Portable HTML reports include screenshots, action logs, session replay, cost, and confidence intervals.

One run. Four layers of proof.

01 · CONTROL

Prove the task is possible

A deterministic positive control validates the environment before an agent is judged.

02 · EXECUTE

Run isolated trials

Fresh recorded Solari browsers make repeated trials practical and reproducible.

03 · VERIFY

Check reality

URL, DOM, and side-effect checks run after the agent reports its claim.

04 · GATE

Ship on numbers

Verified rate and false-positive rate become a CI decision, not a feeling.
